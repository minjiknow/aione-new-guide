공통 UI 요소

대조 기준: 기존 8개 화면의 HTML·페이지 스크립트와 common.css/common.js입니다. 공통 파일에 정의만 있고 현재 화면에서 사용이 확인되지 않은 choice-group, toggle-switch, data-character-current 기반 글자 수 카운터는 사용 예시로 추가하지 않았습니다. 작업 알림은 요청에 따라 가이드에서 제외했습니다. 미리보기용 실행 버튼·예시 문구·생략 범위는 각 항목에 표시합니다.

8개 서비스 화면과 공통 CSS·동적 렌더러의 주요 UI 요소를 대조했습니다. 기본 클래스 열에는 각 요소의 핵심 구성 클래스만 표시했습니다. 예시는 기존 HTML 요소와 공통·화면별 CSS를 표 안에 직접 배치했습니다. 본문 생략과 예시 데이터는 각 항목에 표시했습니다. 문서 생성·저장 등 화면 데이터에 연결된 작업은 원본 화면에서 실행합니다.

    용도 주요 변수 조합 기준
    배경과 테두리 --bg / --surface
    --surface-el / --border         		화면: --bg · 콘텐츠: --surface
    구분 영역: --surface-el · 테두리: --border
    글자 --text / --text-sub
    --text-muted         		기본: --text · 보조: --text-sub
    약한 안내: --text-muted

    --primary-rgb         		기본: --primary · 진한 상태: --primary-dark
    옅은 배경: rgba(var(--primary-rgb), 투명도)
    상태와 고정 계열 --red / --green
    --orange / --purple         		오류·완료 등 기존 상태 색상 사용
    테마 강조색과 별도로 유지

    기존 클래스 조합

    • button button-primary button-sm: 강조 배경·흰 글자
    • button button-soft-primary: 옅은 강조 배경·강조 글자
    • status-badge red / green: 오류·완료 상태
    • 색상 변형은 하나만 사용하고 기존 폰트·아이콘·크기를 유지합니다.

    테마와 강조색 변경

    AIOneTheme.setTheme("dark");  // light · dark · system
AIOneTheme.setAccent("purple");  // default · blue · green · yellow · pink · orange · purple

    테마와 강조색은 독립적으로 설정합니다. default는 기본 강조색으로 복원합니다.

    수정 기준

    • 강조색 변경 시 --primary·--primary-dark·--primary-rgb·--icon-filter-primary를 함께 수정합니다.
    • 페이지별 CSS는 기존 변수 우선 사용. 고정 색상은 별도 확인합니다.
    • 라이트·다크 모드와 hover·선택·disabled 상태를 확인합니다.
