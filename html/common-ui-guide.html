상태 변경

  • 초기 HTML은 common.js가 자동 초기화합니다.
  • 동적으로 추가한 영역은 AIOneSidebar.init(root)를 호출합니다.
  • 접힘 상태는 클래스만 직접 바꾸지 말고 아래 API를 사용합니다.
AIOneSidebar.setCollapsed("#sidebar", true);   // 접기
AIOneSidebar.setCollapsed("#sidebar", false);  // 펼치기

너비 조절과 확인 사항

  • 경계 드래그로 너비를 변경하고 더블클릭으로 220px로 되돌립니다.
  • 키보드는 좌우 화살표로 10px씩 조절하며 Home·End는 최소·최대, Enter는 기본값입니다.
  • 접힌 상태와 768px 이하에서는 너비 조절을 사용하지 않습니다.
  • 작은 화면의 자동 접힘은 페이지별 configure 설정을 따릅니다.
  • 메뉴 선택·Work/Chat 이동·접기·너비 복원·계정 메뉴를 확인하고, 원본의 ID·data-*·aria-* 및 아이콘을 유지합니다.

색상 관리와 조합 기준

  • 공통 색상은 css/ai-theme.css의 CSS 변수로 관리하고, 실제 UI에는 css/common.css의 기존 색상 클래스를 조합합니다.
  • 모드와 강조색 선택은 js/ai-theme.js가 처리합니다.

기존 클래스 조합

button button-primary button-sm: 강조 배경 + 흰 글자, hover는 --primary-dark.

button button-soft-primary: 옅은 강조 배경 + 강조 글자, hover는 강조 배경 + 흰 글자.

status-badge red / status-badge green: 기존 오류·완료 등 상태 표현에 사용합니다.

  • 색상 변형은 같은 컴포넌트의 기존 클래스를 선택합니다.
  • 서로 다른 색상 변형을 중복하지 않고, 폰트·아이콘·크기·간격은 원본을 유지합니다.

테마와 강조색 변경

AIOneTheme.setTheme("dark");  // light · dark · system
AIOneTheme.setAccent("purple");  // default · blue · green · yellow · pink · orange · purple
  • API는 html의 data-theme·data-accent-color와 설정 UI를 갱신하고 선택값을 localStorage에 저장합니다. default는 모드별 기본 강조색으로 돌아갑니다. 위 예시의 두 설정은 서로 독립적으로 선택합니다.

색상 정의를 수정할 때

  • 공통 강조색 변경은 ai-theme.css에서 --primary·--primary-dark·--primary-rgb·--icon-filter-primary를 함께 맞춥니다.
  • 화면별 색상 보정은 해당 페이지 CSS에서 기존 변수를 우선 사용합니다. 현재 일부 배경·테두리·아이콘 색상은 고정값이므로 변수 변경만으로 전체 UI가 바뀌지는 않습니다. 라이트·다크 모드와 hover·선택·disabled 상태를 함께 확인합니다.
